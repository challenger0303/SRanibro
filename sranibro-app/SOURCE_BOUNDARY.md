# Application source

This directory contains the SRanibro application UI, configuration, eyelid and eyebrow inference, post-processing, calibration, output, model-gaze integration, recorder, replay tests and SDK adapter interfaces.

Build instructions are in [README.md](README.md). Available tracking paths depend on the configured adapters and runtime dependencies. Ready-to-run Windows packages are available from the [official releases](https://github.com/challenger0303/SRanibro/releases).

See [SOURCE-LICENSE.md](SOURCE-LICENSE.md) for the application source terms. The sibling `sranibro-core` retains its MIT license.
